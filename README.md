# Условие задачи
Хозяин хочет оклеить обоями длинную стену в своем доме. Длина этой стены равна Амю, а высота Б м. Рулон обоев имеет длину 12м. и ширину 1м. Сколько будут стоить обои для всей стены, если цена одного рулона К руб.

 2. Объявить константы:
*  `A = 6` - длина стены (м)<br>
*  `M = 3`; - высота стены (м)<br>
* `L = 12`; - длина рулона (м)<br>

* Если `S_wall` % `S_roll !=0`, то увеличить `num_rolls` на 1
7. Вычислить общ. стоимость:
* `total_cost` = `num_rolls` * `K`
8. Вывести результаты:
* Площадь стены

* Кол-во рулонов
